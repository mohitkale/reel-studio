## Commit attribution

- Codex-assisted commits include
  `Co-authored-by: Codex <codex@openai.com>` using the
  [OpenAI commit convention](https://github.com/openai/symphony/blob/main/.codex/skills/commit/SKILL.md).
  Its GitHub account is [`codex`](https://github.com/codex).
- Cursor-assisted commits can include
  `Co-authored-by: Cursor <cursoragent@cursor.com>`.
- Keep the maintainer as author/committer and preserve co-author trailers in the
  final PR merge message. Verify account-linked co-authorship on GitHub.
- Credit only agents involved in a change. Preserve existing human attribution
  and never invent identities or rewrite published history.

GitHub's repository Contributors view is derived from commits on the default
branch and may refresh asynchronously. A README entry alone does not change it.
See [GitHub's contributor rules](https://docs.github.com/en/repositories/viewing-activity-and-data-for-your-repository/viewing-a-projects-contributors).
