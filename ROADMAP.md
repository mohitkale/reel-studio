# Roadmap

Reel Studio is a local-first content factory: an LLM writes one storyboard JSON,
and voice, scenes, captions, audio and MP4 export run locally and deterministically.

The plan lives in GitHub:

- [Roadmap issue #140](https://github.com/mohitkale/reel-studio/issues/140): product, principles, order of work
- [Milestones](https://github.com/mohitkale/reel-studio/milestones): the issues in each release
- [Open `agent-ready` issues](https://github.com/mohitkale/reel-studio/issues?q=is%3Aissue+is%3Aopen+label%3Aagent-ready)

Released versions: [releases](https://github.com/mohitkale/reel-studio/releases)
and [CHANGELOG.md](CHANGELOG.md).
