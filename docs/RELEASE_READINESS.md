# Release readiness

What has to be true before `v1.0.0` (roadmap L6, issue #139), what is checked by a command, and
what is still open. 1.0 is a promise that the storyboard contract, the command line and the MCP
tools are stable; nothing is tagged until every line below is ticked with evidence.

```bash
npm run release:ready            # every check a machine can run, in one table
npm run release:ready -- --quick # skips the production build, browser journeys and frame check
```

It writes `.artifacts/release-ready.json`, exits 1 if anything that ran failed, and lists the
checks that need a person or a published package as **waiting**, never as passed.

Status as of 20 Nov 2026 (package version 0.8.0; the next release number is the maintainer's call).

## Known gaps

Found while preparing this list. None is a reason to hide the release; each is a reason to say
so plainly (see the claims table in [LAUNCH.md](LAUNCH.md#3-what-we-can-say-and-what-we-cannot-yet)).

- **The npm package.** Private, 64.5 MB, 1,877 files, with no `files` allow-list. Publishing it is
  its own piece of work (#110, #117).
- **MCP client install guides** are written from each client's documentation; none has been run in
  the real client (#208 to #211).
- **`sharp` is used but not declared** (#234). `src/library/visual-review-contrast.ts` imports it, and
  `package.json` does not list it; it arrives through `@huggingface/transformers`. It works, and
  it will break if that chain changes.
- **The look of the output is not where the maintainer wants it.** On 20 Nov the maintainer
  reviewed real-content videos (NASA photographs, a Mars explainer) and found the visuals, the
  sound and the voice not premium. This release fixes loudness (-16 LUFS, no chimes, a quiet music
  bed), makes picture scenes show the photograph, and puts text scenes over supplied pictures
  (#246). The 16/20 rubric in [QUALITY.md](QUALITY.md) has still not been scored by a person.
- **Nobody has watched or listened to** the lip sync, the stings, the beat-aligned scene starts or
  the launch video end to end.
- **No real Ollama run** (the writer success target is unmeasured, #191), no real ComfyUI run, no
  10-minute recording run, and non-English pronunciation is unsupported (the vendored eSpeak has the
  English dictionary only).
- **Windows** is exercised in CI only.
- **The dark-theme `terminal` scene** draws on a light panel with small text.

## For the release itself

1. `git pull --ff-only` on `main`; wait for the full CI (`ci:full`) green on that commit.
2. `npm run release:ready` (no `--quick`); attach `.artifacts/release-ready.json` to the release issue.
3. `npm run showcase`, review the videos, link the review.
4. On a clean machine of each system: `npx reel-studio@<version>` through the first video
   (after M1).
5. `npm run release`, then publish the package and the release with the showcase videos.
6. Re-run `npm run demo:assets` and `npm run launch:assets` if the product changed, then follow
   [LAUNCH.md](LAUNCH.md).
