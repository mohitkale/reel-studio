# M3 sequence and continuity acceptance

Historical acceptance record, 2026-10-17. Current behavior is documented in
[sequence direction](../SEQUENCE_DIRECTION.md). The M3 PR records latest-head
platform CI and delivery; it must pass before merge and local main refresh.
M0 and M4–M6 are not certified by this record.

## Scope and regression evidence

- Deterministic search: six admitted candidates, three-scene lookahead, six
  retained paths. A synthetic 12-beat comparison reduces unmotivated repetition
  against the M2 greedy planner. It is not a blind human quality benchmark.
- Stable literal-label identities, explicit aliases, ambiguity rejection,
  saved brand color slots and source-bound explanations with compatible choices.
  Locks, hidden copy, semantic illustrations, ordered relationships, source text
  and narration remain protected.
- Resolver `1.2.0` freezes ports and adapter `adaptive-panel-handoff@1.0.0`
  boundaries, including fallback reasons. Existing M1/M2 resolvers remain valid.
  Source/geometry tampering is rejected; SQLite checkpoint/read/restore and
  idempotent replanning preserve settings and decisions.
- Boundary tests exercise both scoped HTML and actual written-directory cache
  hashes: endpoint edits invalidate both affected sections; a nonempty unrelated
  later section remains identical. Native manifest/media validation and audio
  assembly retain their existing coverage.
- Broader local suite: 953 tests across 187 files passed before the final
  section-directory regression was added. The final focused run passed 75 tests across 13 files; typecheck, lint and
  secret scanning and the production build passed. Atomic append registration also passes the existing
  SQLite race/cancellation integration test; full latest-head Linux/Windows suites remain CI gates.
- A local single-run synthetic 240-scene planner sample completed in about 47 ms.
  This is a reference measurement, not a hardware or whole-render guarantee.

## Actual examples

The active app library contains three synthetic seven-scene films, each with
silent placeholder audio, an immutable revision and an accepted MP4. The examples
vary subject counts/positions; the first includes an explicitly configured
Collect/Gather alias. No AI/media/voice provider, paid generation, dependency
installation, model download or runtime upgrade was used.

| Project               | Format    | Visual family | Acceptance output           |
| --------------------- | --------- | ------------- | --------------------------- |
| M3 · Connected work   | 1080×1920 | Precision     | 42 s / 1260 frames / 30 fps |
| M3 · Review sequence  | 1920×1080 | Editorial     | 42 s / 1260 frames / 30 fps |
| M3 · Publishing route | 1080×1080 | Graphic       | 42 s / 1260 frames / 30 fps |

Each uses the isolated native worker with actual section caching/assembly. A
shared-card boundary crosses the 30-second section split. Unsupported row/column
pairs retain their existing transition. Acceptance inspects settled scene frames
and transition frames around the split, complete copy, subject colors, target
geometry and final frame counts.

Browser checks cover the saved decision explanation, identity editor, rejection
of an ambiguous alias, saving/reloading an explicit alias, and forward/reverse
seeking at active handoffs. Visible computed states are compared; inactive
future overlays may serialize fractional positions differently before first
activation, without a visible frame difference.
The final production build passes forward/reverse checks at 6.1 and 30.1 seconds
in all three formats. Comparisons normalize `none` and an identity transform
matrix, which have identical geometry. Screenshots show the
[editor](../assets/adaptive-m3/editor.png) and
[saved alias](../assets/adaptive-m3/subject-identities.png).

The initial direct-render attempt exposed a dropped sequence setting in the
native fallback input. That path now uses the same sequence configuration mapper
as prepared renders, immutable specs, film-plan capture and editor playback.
Native frame review also led to declaring each handoff as a timed scene on the
existing per-scene clock, with source/target visibility on their own timelines.
A real-GSAP test checks overlay windows and reverse seeks. Frozen native capture
was inspected before, during and after handoffs, including reverse seeks. Scene
contact sheets select exact frames at 3, 9, 15, 21, 27, 33 and 39 seconds;
low-rate FPS resampling would instead select transition moments. Accepted exports
were regenerated after the adapter changes.

## Boundaries

The registry records identity and supplied symbols; M3 only decorates and carries
adaptive comparison/process cards. It does not move arbitrary diagrams or media,
change the story, extend duration limits, or establish local-model creative
quality. The saved upgrade plan retains M0 and later workflow/long-form/factory
acceptance gates. Accumulate toward a coherent creator-facing feature release;
M3 alone does not satisfy the full release matrix or M4 creation workflow.
